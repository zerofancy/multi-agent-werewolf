# 多 Agent 狼人杀 · multi-agent-werewolf

由主 Agent 担任法官，12 位独立子 Agent 实际参与狼人杀。每位玩家有名字、头像、人物背景、性格和说话方式，身份与信息按实际权限隔离。

## 功能

- 有警长的 12 人预女猎守：4 狼、预言家、女巫、猎人、守卫、4 平民。
- 警长竞选、警徽传递、正常环形发言；每位玩家读完此前公开发言再表态。
- 投票使用同一公开截止快照，各自独立锁票，全部收齐后统一公布。
- 本机 HTTP 轮询实时观战，逐人发布，保留阅读位置与展开状态。
- 完整离线 HTML 时间线，区分全体公开、狼队私聊、法官私聊和未传话内心。
- 终局向胜方 2 位、败方 1 位原玩家投递全局总结，再收集真实感言；导出后关闭临时服务。

## 安装与使用

需要支持独立子 Agent 创建与续接、文件读写和本机进程的 Agent 环境，以及 Python 3.10+。运行脚本仅依赖 Python 标准库。Skill 不包含模型服务或通用游戏调度器，需由宿主 Agent 按协议主持与传话。

将本仓库克隆或复制到 Codex 的 `~/.codex/skills/multi-agent-werewolf`，然后请求：

> 使用 $multi-agent-werewolf 开一局 12 人狼人杀，开局打开实时观战，结束生成离线复盘并关闭临时 HTTP 服务。

入口：[SKILL.md](SKILL.md)。其他 Agent 工具可按自身 Skill 加载方式使用；子 Agent 和浏览器工具名称需与运行环境对应。

## 当前限制

实时观战依赖浏览器轮询；后台标签、休眠或连接中断可能延迟同步。最近一次完整对局中，服务端持续发布正常，但浏览器端出现停滞，其根因尚未确认；当前版本保留这一已知限制。最终离线复盘独立于临时服务，可完整阅读。

观战页为包含真实身份、私聊和内心的全知视角，不能交给游戏中的玩家查看。运行目录含私密对局数据与随机服务控制令牌，不应提交到公共仓库。
