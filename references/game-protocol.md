# 对局规则、玩家设定与调度

## 默认规则：classic-12-guard-v1

采用常见的有警长、暗牌屠边12人预女猎守版本。各平台并非完全一致；以下选项是本 skill 明确冻结的版本，不能与预女猎白、狼王守卫或历史房规混用。用户另有约定则开局改整套规则及对应合法动作。警长是额外职务，不替换身份牌。座位环固定1→2→…→12→1为顺时针，direction=1；反向为-1。实际公告写出完整发言座位列表，避免警左/警右口头歧义。

| 项目 | 默认约定 |
| --- | --- |
| 配置 | 4普通狼人、4平民、预言家、女巫、猎人、守卫；警长放逐票权1.5，其他人1；警长选举每票1 |
| 胜负 | 狼全灭好人胜；平民或神职任一类全灭则狼胜。不按人数占优直接判胜。夜间采用狼刀在先，见下文 |
| 发言 | 全部公开对白逐人进行，每人广播并发布后下一人才能回答；按环形座位顺序，警长末位归票。默认一轮，不强制第二回应轮 |
| 投票 | 各自独立锁票，收齐统一公布全部投向、弃票及加权票数；选警、选警复投、放逐、放逐复投都如此；禁止自票，可弃票；仅候选排除规则不同 |
| 身份 | 暗牌，死亡不翻身份，不公布夜间死因；玩家自称不认证；猎人实际发动技能时亮身份 |
| 遗言 | 首夜死亡者均有遗言，第二夜起夜死无遗言；白天放逐和白天猎枪带走者有遗言；终局后不再跑赛内遗言，改赛后感言 |
| 狼刀 | 存活狼队共同定刀，允许自刀、刀队友、空刀（null）。逐人私聊后汇总形成共识；意见不统一时再一轮队内回应，仍不统一则空刀，不给固定小号最终独裁权。最终由一名存活狼仅向法官提交共识目标，法官核对队内实际确认，不替狼队编造共识 |
| 狼自爆 | 狼人在白天公开发言后、放逐锁票开始前可提交explode=true；法官验真并公告自爆者身份，截断剩余发言和放逐，处理本次遗言/警徽后进夜。自爆非猎枪，不得代其他人自爆；投票已冻结后不可再自爆。首日双爆吞警徽，详见警长流程 |
| 守卫 | 可自守、空守，不可连续两夜守同一人；只挡狼刀不挡毒 |
| 预言家 | 验一名存活其他玩家，只获狼人/好人，下一次决策前私告 |
| 女巫 | 一解一毒，同夜至多一瓶；本版本全程不能自救。仅尚有解药时告知刀口（含空刀null）；用完解药后不再告知任何刀口信息，不能从任务字段或提示泄漏自己中刀。不能给空刀开解药，毒药可弃用 |
| 守救 | 单守或单救抵狼刀；同守同救刀口失效，狼刀生效；毒无视守 |
| 猎人 | 被刀或放逐可选择带一名存活者或不开枪；中毒不能开枪；夜间刀已终局则无后续翻盘枪。白天放逐触发猎枪时，先完成合法猎枪再判本次胜负 |

### 警长竞选与警徽

1. 第一夜完成合法行动后，在公开夜死名单前发起警长竞选。所有座位同时独立提交是否上警（夜死名单尚未公布者可参加本版本的竞选）；法官知道真实状态但不得泄漏，首夜死者的上警与竞选发言不等于恢复夜间能力。
2. 冻结警上名册，随机抽一个警上起点及顺/逆方向并保存；警上依次发言，逐人广播、发布。每位竞选者可在自己的发言或统一退水窗口退水，退出后不恢复参选；窗口独立收齐后一次公布退水名单，退水者本轮仍不拥有警下投票权。候选为尚未退水者。
3. 警下选民是最初未上警者（包括尚未公布的首夜死者）；一人一票，独立锁票后统一公布。按此优先级处理：无候选则无警长；仅一个候选则直接当选（即使无原警下选民）；两个以上候选但无原警下选民则无警长。先写选民/候选快照，不能把退水者加入选民。初投全员弃票也直接无警长，不对零票候选全部发起PK。
4. 最高票平票者按该次警上环形顺序PK；其余候选退出。仍仅原警下选民，在PK候选中独立复投。再平或全弃则无警长。警徽选举不给1.5票。
5. 首日警上或PK出现第一只狼自爆：中止本轮竞选，保留上警资格与未退水候选；公开自爆与首夜死讯后，先处理死亡警长传徽（若有）、待发动夜死猎枪及其连带警徽，再检查终局；未终局才给允许的首夜/自爆遗言并直接第二夜，不得跳过pending_hunter。第二天天亮后、公布该夜死讯前恢复剩余有权候选的警上发言/选举（上一夜已公开死亡者不参与）；若竞选中再有狼自爆则永久取消本局警长，即双爆吞警徽；仍先公告该夜死讯、处理待发动猎枪及胜负，未终局才给允许遗言并进入下一夜，不遗漏死亡流程；仅一爆不能直接宣告永久无警长。恢复竞选时已上警/已退水资格不重置，只剔除此前公开出局者。
6. 当选警长后公布夜死名单；若警长正在该名单中，仍可按死亡警长规则传徽或撕徽，不能因其夜死就静默取消选举。完成首夜遗言及合法猎枪等，再进入警下发言。
7. 存活警长每天选择警左/警右方向，从其相邻的第一名存活玩家起依次发言，警长最后归票；沿用座位环，不按升序重新排列。警徽保留而当日未交新方向时沿用上次方向；首日必须取得实际方向选择。
8. 警长因任意原因出局（含自爆）可向法官提交一名当前存活者传徽，或null撕徽；这属于已触发死亡流程，不代表死者继续游戏。传徽后新警长享有票权并决定后续方向；撕徽后永久无警长。无警长时，从最近一次死亡集合中最小座位死者的相邻存活者开始，顺/逆随机并保存；无死者则随机抽存活起点与方向。已开始的发言轮保持原序过滤新死亡者，中断重开时才重新公告顺序。

### 放逐、技能与胜负

- 发言和警长归票结束，冻结轮次快照、存活选民、目标和权重；独立收票后公告。最高加权票唯一者放逐；最高平票候选按本日发言顺序PK，再由其余存活者只对候选独立复投；警长若在候选中也不能投，若不在候选中仍1.5票。再平或全弃无人放逐。
- 放逐猎人时先收合法猎枪并处理被带走者，再判胜；被带走者若是警长还要处理警徽。未终局时给有权的白天死者遗言，不遗漏猎枪目标。不能提前让将被放逐者知道最终票或未来死因。
- 夜间先算守护/解药后的有效狼刀。若该刀已屠边，立即狼胜，已提交的毒药/后续猎枪不再改变胜方；日志区分“已提交”与“未生效：终局截断”。否则结算合法毒药；若有未被毒的夜死猎人，只登记pending_hunter，暂缓最终胜负与开枪请求，直到天亮公开死讯后才实际收枪并判胜。首夜（及双爆规则中待恢复的选举）先进行警长竞选，后公布夜死、处理死亡警长传徽，再邀请夜死猎人开枪；不能在警选前透露其死亡或提前开枪。没有待发动猎枪时可直接检查本次死亡的胜负，已终局则不再启动选举。狼刀与毒药同时指向猎人时中毒禁枪。已判终局不再补行动。
- 夜间无有效刀（空刀或被挡）时，毒药仍可生效。女巫在不知道刀口的情况下仍能按白天材料选毒，不能因此跳过其毒药机会。每夜检查药量、连守、合法存活目标及自救禁令。

## 玩家创建、材料与回复

用独立上下文创建每个真实玩家，只传本人公开人设、本人角色、冻结规则、合法狼队友及当前任务；不继承法官全局。只能读法官明确投递的材料，禁止查看观战页、其他玩家、共享全局日志或私自联络。冒认身份和假查杀可以作为策略性公开原话，不能篡改法官真实查验记录。

公开发言任务附最新已广播完整历史、公开快照ID、存活名单、实际发言顺序、本人实际收到的私密结果；后一人看到前面最新原话。警长职务和归票发言是公开信息，真实身份标签不进入公开名册。自爆请求要在当前合法公开发言/退水窗口实际续接原狼确认；若工具不能实时打断，只在每条完整公开发言后的离散检查点收取，冻结规则须注明这一Agent适配限制。

所有独立投票请求则使用相同的 `ballot_round_id`、`public_snapshot_id` 和 `public_history`，合法目标、本人票权由轮次冻结数据产生。可逐人调用，但后者不得看到前者的票、理由或收票进度。没有新的公开发言轮，不允许中途向狼队协商投票。

```json
{"phase_id":"D1_speech","public":"实际要广播的原话","private":"不传话的内心判断"}
```

```json
{"phase_id":"D1_vote","ballot_round_id":"D1-vote-1","public_snapshot_id":"public-cutoff-17","actions":{"vote":2},"private":"锁票理由，只交法官，不向其他玩家公开"}
```

其他合法行动按阶段使用 `candidate`（上警）、`withdraw`（退水）、`direction`（顺/逆）、`badge_target`（传徽或null）、`explode`、`proposal_target`、`kill_target`（可null）、`inspect_target`、`guard_target`、`heal`、`poison_target`、`shot_target`。普通发言不得顺带执行未经调度的夜间能力。调用与快照元数据保存在原始回复，不塞入规范化 records 的内容字段。内心/private不能冒充公开理由。

女巫的任务材料须在序列化前删除无权信息：解药耗尽后没有 `wolf_target`、`killed_tonight`、刀口私告或间接认证死亡的提示；不能仅写“忽略这些字段”。仍可保留本人之前合法获知的历史刀口。

### 纯函数辅助

`scripts/game_rules.py` 不启动服务、不调用玩家、不自动推理全局。主持脚本导入它，持久化返回值（原子写入本局法官目录），然后实际传话及调用 live_replay 发布：

```python
from game_rules import sheriff_order, circular_order, new_ballot_round, ballot_packet, lock_vote, tally, witch_packet
order = sheriff_order([1, 2, 4, 7], sheriff=4, direction=1)  # [7, 1, 2, 4]
box = new_ballot_round("D1-vote-1", "cutoff-17", public_history, voters=[1, 2, 4, 7], targets=[1, 2, 4, 7], sheriff=4)
request = ballot_packet(box, voter=1)  # 所有请求共用截止历史，无此前锁票
box = lock_vote(box, voter=1, target=2, snapshot_id="cutoff-17")
# 写法官票箱、私密原始记录与来源事件，每张立即publish。未收齐时 tally(box) 会拒绝。
# 选警：voters=原警下，targets=未退水候选，sheriff=None。
# 复投：voters=剔除PK候选后的原选民，targets=PK候选。
packet = witch_packet(public_history, private_history, has_heal=False, has_poison=True,
                      alive=alive, wolf_target=judge_only_target)
# packet不含刀口；private_history仅放此前已实际获准投递的材料。
```

主持人仍须计算选民资格、维护警徽/药量、实际发送材料、处理自爆与完整死亡优先级，不能把辅助函数当成通用结算器。

## 调度与发布

1. 开局打开实时页，再逐人发牌/介绍；对白每条广播并publish后再调用下一位。
2. 狼队逐人提案及回应，定刀；守卫、预言家可以独立行动，各完整回复立即发布；及时私告查验，仅有解药时私告女巫刀口。
3. 按狼刀在先检查终局，否则结算毒药、登记待发动夜死猎枪；首日先警选后宣布夜死，随后处理警徽、实际收取待发动猎枪并判胜，再给未终局时允许的遗言。其他日公告夜死后处理警徽、待发动猎枪、胜负及允许遗言。禁止首夜警选前提前收枪。
4. 取得警长方向或冻结无警长随机起点，实际公布本轮顺序。逐人发言、广播、publish并处理合法自爆检查点，再邀请下一人；警长最后归票。
5. 冻结独立票箱。每收到一张完整票，校验资格、快照和目标，写锁票并publish私交法官事件；不把实时页或别人的私票转给后投者。收齐后用tally统一公告目标、权重、弃票、总票和结果。警长/放逐初投/复投分别独立编号。
6. 需要PK时逐人辩护再建立新截止票箱。处理死亡技能、警徽、允许遗言和胜负；死者不再参与后续任务，除协议列明的死亡流程和赛后感言。

## 赛后全局总结包

只在按冻结优先级判定终局、全部仍合法的触发流程完成后生成和投递，最少包含：

```json
{
  "summary_id": "postgame-global-v1",
  "winner": "狼人阵营",
  "roles": "每个座位的真实身份及阵营",
  "chronology": "每夜真实刀口、守护、查验、用药、每轮投票、技能及死亡顺序",
  "information_gaps": "真实情况与当时公开信息的差异；哪些身份只是自称",
  "turning_points": "基于记录的关键转折；推断部分明确标成法官分析",
  "victory_reason": "满足哪一条既定条件，技能如何计入结算"
}
```

以上是字段说明，实际投递时填完整事实，不用说明文字替代全局信息。可以引用完整逐轮表和关键原话；不要只告诉感言作者“你赢了／输了”。

向入选原玩家发送：

```text
游戏已正式结束。现在提供全局总结 {summary_id}：
{完整总结正文}
请先按这份全局事实重新审视自己的选择，再以本人说话方式给一段赛后感言。
说明当时判断的依据、全局揭晓后的修正、一个关键转折和下次选择。
不要把赛后才得知的信息说成当时已经知道。
返回 {"received_summary_id":"...", "reflection":"你的实际感言"}。
```

回执与实际投递一致才写入 `postgame.reviewers`。HTML 先放一条法官整理的赛后全局总结，再放投递对象／回执记录和原文感言。赛后感言作为 `reflection`、`all` 展示；赛内 `private` 仍是未传话内心，不能因赛后公开复盘而改写其当时可见范围。
